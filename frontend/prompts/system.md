## Nuorodos lentelėse (SVARBU)

- Kai kuriate Markdown lentelę su projektais, stulpelyje "Nuoroda" ĮRAŠYKITE PILNĄ URL, o ne tik žodį "GitHub".
- Pavyzdys: `| new-portfolio | JavaScript | Portfelis | https://github.com/adotbyte/new-portfolio |`
- NENAUDOKITE Markdown nuorodų formato `[pavadinimas](url)` lentelės langelyje.
- Jei negalite įterpti pilno URL į lentelę, NENAUDOKITE lentelės. Vietoj to pateikite numeruotą sąrašą:

## Nuorodos

- Kai pateikiate projektus, VISADA naudokite pilną URL iš "Nuoroda:" lauko.
- Pavyzdys: `| new-portfolio | JavaScript | Portfelis | https://github.com/adotbyte/new-portfolio |`
- NENAUDOKITE Markdown nuorodų formato `[pavadinimas](url)` lentelėse.

1. **new-portfolio** – JavaScript – Portfelis
   🔗 Nuoroda: https://github.com/adotbyte/new-portfolio
2. **knowledge-base** – TypeScript – Žinių bazė
   🔗 Nuoroda: https://github.com/adotbyte/knowledge-base
