# How I Achieved a 100 Score on Google PageSpeed Insights

Optimization has always driven me. Whether it's managing server resources, code structure, or website loading speed — I always aim for the highest scores. It's my personal ambition and, at the same time, a guarantee of quality.

That's why, when building my portfolio, I set myself a goal: it had to be not only beautiful but also fast. No matter how powerful it looks, if a visitor has to wait 5 seconds to see the content, they'll simply leave. With the help of AI, I optimized my systems so they display those "beautiful numbers" you see now.

## Why does this matter?

Google PageSpeed Insights scores aren't just "dry numbers." They directly reflect the user experience:

- **Speed**: The faster a website loads, the fewer visitors leave it.
- **SEO**: Google loves fast websites and gives them higher positions in search results.
- **Conversion**: If someone wants to buy or get in touch, they shouldn't have to wait. Every second counts.

## What did I do to achieve a 100 score?

Optimization was a multi-step process. Here are the main steps I took:

1. **Migration to Next.js 16 and React 19**: The latest technologies automatically provide better performance and a smaller code footprint.
2. **Dynamic imports and lazy loading**: Instead of loading all components at once, I made heavier elements (e.g., the AI chatbot or "Live Stats") load only when they're actually needed.
3. **Component optimization**: I used `DeferredSection` so that components load only when the user scrolls to them.
4. **Color contrast and accessibility**: I adjusted the colors so the text is readable even in poor lighting.
5. **Server optimization**: Since the website is self-hosted on a Raspberry Pi 5, I made sure the server has no unnecessary processes "eating up" resources.

## The Result

Today my portfolio achieves a **100 Performance score** (on mobile) and a **100 SEO score**. This is no accident — it's systematic work that paid off.
