# How I Achieved 100 Points on Google PageSpeed Insights

Optimization has always driven me. Whether it's managing server resources, code structure, or website loading speed — I always aim for the highest scores. It's my personal ambition and, at the same time, a guarantee of quality.

That's why, when I built my portfolio, I set myself a goal: it had to be not only beautiful but also fast. No matter how powerful it looks, if a visitor has to wait 5 seconds to see the content, they'll simply leave. With the help of AI, I optimized my systems so that they display those "beautiful numbers" you see now.

## Why does this matter?

Google PageSpeed Insights scores aren't just "dry numbers." They directly reflect the user experience:

- **Speed**: The faster a website loads, the fewer visitors abandon it.
- **SEO**: Google loves fast websites and gives them higher positions in search.
- **Conversion**: If someone wants to buy or get in touch, they shouldn't have to wait. Every second counts.

## What did I do to reach 100 points?

Optimization was a multi-stage process. Here are the main steps I took:

1. **Next.js 16 and React 19 migration**: The latest technologies automatically provide better performance and a smaller code footprint.
2. **Dynamic imports and lazy loading**: Instead of loading all components at once, I made it so that heavier elements (e.g., the AI chatbot or "Live Stats") are loaded only when they're truly needed.
3. **Component optimization**: I used **DeferredSection** so that components are loaded only when the user scrolls down to them.
4. **Color contrast and accessibility**: I adjusted the colors so that text remains readable even in poor lighting conditions.
5. **Server optimization**: Since the website is self-hosted on a Raspberry Pi 5, I made sure the server didn't have any unnecessary processes "eating up" resources.

## The result

Today, my portfolio reaches **100 points in Performance** (on mobile) and **100 points in SEO**. This is no coincidence — it's the result of systematic work that paid off.
